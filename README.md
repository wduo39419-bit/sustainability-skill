# Sustainability Skill

一个面向科研、产业与创新创业项目的可持续技术评估 Skill，从**绿色经济与碳排放、实际盈利能力、落地可行性**三个维度，判断一项技术是否具有真实价值和进一步投入的必要性。

## 项目介绍

许多新技术在展示时强调创新性，却缺少对环境收益、商业回报和实施条件的系统验证。Sustainability Skill 将技术说明、项目计划书、实验数据、财务预测和应用场景转化为结构化评估，帮助使用者识别技术优势、关键假设、证据缺口和潜在致命障碍。

本项目已经通过智慧渔业、水环境治理、农业资源化和港口污染数字治理等不同类型的科研创新材料进行测试。它不仅给出综合分数，还会区分已验证数据、项目方提供数据、估算值与假设，避免在证据不足时产生过度乐观的结论。

## 核心评估框架

### 1. 绿色经济与碳排放

- 比较技术方案与现有基准方案的生命周期碳排放
- 评估能源、水、原材料和废弃物等资源影响
- 识别减排量、环境协同效益与潜在环境负担转移
- 分析碳收益、绿色溢价、政策激励及单位减排成本

### 2. 实际盈利能力

- 梳理收入来源、客户需求和商业模式
- 分析资本性支出（CAPEX）、运营支出（OPEX）和单位经济性
- 在数据充分时估算毛利、盈亏平衡点、投资回收期、净现值（NPV）和内部收益率（IRR）
- 使用保守、基准和乐观情景开展敏感性分析

### 3. 落地可行性

- 判断技术成熟度、验证强度与规模化难度
- 审查供应链、生产制造、运维和人才条件
- 识别安全、法规、知识产权、客户采用和基础设施风险
- 给出试点路径、验证指标、里程碑和停止条件

## 工作方式

Sustainability Skill 会先明确技术边界、应用规模、地点、时间范围、功能单位和对比基准，再分别完成三个维度的评估。最终结果包含：

- 各维度评分与评分依据
- 综合判断及置信度
- 关键风险和一票否决项
- 证据状态与数据缺口
- 最敏感的技术和财务变量
- 下一阶段验证任务与决策里程碑

建议结论分为：**推荐推进、满足条件后推进、继续验证、现阶段不建议推进**。综合分数仅用于总结，不会掩盖安全、法规、供应链或规模化方面的致命障碍。

## 适用场景

- 科研成果转化与技术路线筛选
- 大学生创新创业项目评审
- 企业研发项目立项和试点审批
- 绿色技术、低碳技术和环保项目评估
- 投资尽调与商业化可行性分析
- 政府、园区和高校的项目遴选

## 发展前景

随着“双碳”目标、绿色金融和科研成果转化需求不断增长，仅评价技术是否先进已经不够，市场更需要同时回答“是否真正减排、是否能够盈利、是否可以规模化落地”。Sustainability Skill 有望进一步发展为标准化的技术价值评估工具。

未来可扩展方向包括：

- 建立能源、环保、农业、制造和数字技术等行业专用评价模块
- 接入生命周期评价（LCA）、碳因子和行业基准数据库
- 增加现金流、敏感性分析和减排成本自动计算工具
- 形成可复用的案例库、风险库和技术成熟度基准
- 自动生成投资备忘录、项目评审报告和试点验证清单
- 支持科研机构、企业、投资机构和政府部门的协同决策

## 安装

将仓库克隆到 Codex Skills 目录：

```powershell
git clone https://github.com/wduo39419-bit/sustainability-skill.git ~/.codex/skills/sustainability-skill
```

安装后重新打开 Codex，或让 Codex 重新扫描 Skills。

## 使用示例

```text
请使用 $sustainability-skill 审查这份技术项目材料，分别评估绿色经济与碳排放、实际盈利能力和落地可行性，并给出证据缺口、关键风险及下一步验证建议。
```

评估质量取决于输入证据的完整性。对于缺少真实成本、规模化实验、客户验证或碳排放数据的早期项目，本 Skill 会明确标注假设和不确定性，而不会将结果包装成精确的投资结论。
